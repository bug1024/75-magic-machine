# 75's MAGIC MACHINE

一个给女儿做的网页小玩具，把她熟悉的玩具、家人、宠物和想象中的宝物，放进一座会慢慢成长的魔法花园。

按下空格，彩灯亮起、小球翻腾，机器送出一件惊喜。宝物不必在现实中兑现：一条公主裙、一颗会飞的宝石，甚至可爱的便便，都可以让她开心。希望她能自己操作、收集伙伴、创造故事，也亲手守护自己的小世界。

## 游戏机制

### 抽奖与能量

- 空格键或底部大按钮启动抽奖；即使切到合成视图，大按钮仍负责抽奖。
- 初始有 10 颗爱心，每次抽奖消耗 1 颗。剩余不超过 3 颗时出现红色预警。
- 数学充能每答对一题补充 2 颗爱心，上限 10 颗；难度可选 10、20、100 以内加减法，答错不扣能量。
- 宝物可收藏、点击互动和摆放。普通抽奖适当照顾未收集宝物并减少连续重复；作弊模式默认关闭，开启后按相同概率抽取。

### 机器成长

只有正常抽奖推进成长，访客和战斗赠品不计次数。机器升级时保留已有元素，同时改变外观和声音。

| 正常抽奖次数 | 成长阶段 |
| --- | --- |
| 初始 | 星光机 |
| 10 次 | 彩虹机 |
| 20 次 | 飞翼机 |
| 35 次 | 城堡机 |
| 50 次 | 生命树 |
| 75 次 | 「75 的魔法之夜」大结局 |

### 花园与合成

花园有 6 个宝物槽位，用于装饰、互动和守护。摆放数量受实际库存限制，移走后可以重新摆放。

机器中央提示当前合成目标和缺少的伙伴。切到合成舱，邀请两三件不同的已获得宝物，观看伙伴汇聚、融合，再一起演出故事。合成不消耗宝物，也不占用花园槽位。

故事会留下永久景物，数量增多后可翻页查看。其中音乐花能补充能量，许愿石能提高指定未收集宝物的抽中机会，守护旗能抵挡一次破坏；补能和防护能力有抽奖次数冷却。

### 天气、访客与守护

- 四季随机器升级变化，昼夜每 3 分钟前台游玩时间交替。天气每隔随机 3～6 次正常抽奖出现，包含雨雪、流星、冰激凌雨、金币雨、樱花雨和风暴，可通过简单点击获得能量与纪念物。
- 仙子最多补充 5 颗爱心，幽灵会捣蛋，美人鱼和快递精灵会送来可点击打开的礼盒。
- 每次升级解锁新的反派：蝙蝠、女巫、石头怪、大龙。它们直接在花园出现，点击发射宝物将其赶跑，也可从「守护挑战」主动邀请已解锁的反派。
- 反派会困住伙伴、吸走能量或撞倒设施。具有守护能力的宝物必须实际摆放才会助攻或防护，最后一击留给孩子。胜利后救回伙伴、归还能量，倒下的设施可点击修复，收藏不会丢失。

升级、访客、故事和战斗依次演出，天气让位于这些事件。待处理事件优先于下一抽，零能量也能继续迎接伙伴或守护花园。

### 有结局，也能一直玩

第 75 次正常抽奖触发魔法之夜：伙伴回归、生命树开花、大龙恢复善良，最终获得普通奖池中没有的「75 的星光皇冠」。

结局后可进入「永恒花园」，继续抽奖、合成、天气互动和守护挑战。曾经的反派也会成为花园的守护伙伴。

## 运行与存档

游戏使用原生 HTML、CSS 和 JavaScript，无后端。构建后的 `index.html` 内嵌配置、插画和脚本，可直接打开、离线游玩；支持静音、柔和动画与全屏。

进度自动保存在当前浏览器，设置中可导出、导入存档。

```sh
npm run build   # 修改源码或配置后重新生成 index.html
npm start       # 需要 Python 3，打开 http://localhost:7575
```

开发检查：安装依赖 `npm ci`，安装测试浏览器 `npx playwright install chromium`，运行 `npm run check`。

宝物配置在 `treasures.json`，组合故事在 `garden-stories.json`，天气互动在 `garden-adventures.json`，游戏规则在 `game-config.json`；源码在 `src/`，插画在 `assets/`。
