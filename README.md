# 75's MAGIC MACHINE

一个给女儿做的网页小玩具。

按下空格，魔法机器就会亮起来：彩灯追逐、小球翻腾、扭蛋落下，最后冒出一件宝物。宝物里有她熟悉的小海豚、吱吱猫头鹰、丫丫三花猫，也有公主裙、月亮城堡和一些让人笑出声的小东西。

想做的是一个她能自己玩、每次打开都有一点期待的小世界。虚拟的裙子、会飞的宝石或可爱的便便，都可以成为让她开心的惊喜。

## 设计理念

### 操作简单，过程热闹

主要操作只有一个：按空格键，或点击「开启魔法」。空格键始终用于启动抽奖，焦点停在哪个按钮上都不会改变它的用途。

乐趣也在等待宝物出现的过程中。能量注入、小球碰撞、落球、摇晃、开壳，每个阶段都有动作和声音反馈，让一次简单的点击变成一场小小的魔法表演。彩色灯光、夸张动画和带节奏的中奖音乐共同营造气氛；声音和柔和动画可以单独切换。

机器有 10 格魔法能量，每次抽奖消耗一格。剩余不超过 3 格时，屏幕边缘以红色脉冲闪烁，并间歇播放专属提示音；能量耗尽后，可以用数学题给机器充电。答对一题增加一格，最多存满 10 格，答错不扣能量，也没有倒计时。机器底部用爱心显示剩余能量；进入答题面板后暂停预警，静音关闭提示音，柔和动画保留静态红色提醒。补充能量的过程同样是一场有小星星和声音反馈的魔法。

### 熟悉的生活，也能成为魔法

宝物把现实中的玩具、家人、宠物和想象中的物品放在一起。每件都有自己的插画、名字、描述和开奖效果，让孩子熟悉的小东西也能带来新鲜感。所有宝物都是虚拟奖励，收藏记录留在当前浏览器中。

### 宝物由配置驱动

宝物内容与抽奖流程分开。`treasures.json` 定义「有什么宝物、出现的概率、长什么样、用什么效果」，程序负责抽取和演出。

添加宝物时，可以直接补充配置和 SVG 插画，复用已有的星光、彩虹、月光或泡泡效果。如果需要新的表现，再扩展对应的动画或音效实现。

### 保持轻巧，方便打开

使用原生 HTML、CSS 和 JavaScript，没有框架、CDN 或后端。构建后，配置、插画、样式和脚本全部内嵌到一个 `index.html`，可以复制到其他电脑，直接用浏览器打开。

## 试玩

用 Chrome / Edge 打开 `index.html` 即可游玩。

- 按空格键或点击「开启魔法」抽取宝物。
- 右上角可以切换声音、柔和动画和全屏。
- 「我的宝藏」展示收集到的宝物。
- 「充能」随时可打开数学小站，简单、中等、困难分别对应 10、20、100 以内的加减法，运算数和结果均在范围内，减法不出现负数。简单题配有可数的星星；答错后可以看提示再试。
- 能量耗尽时，启动按钮和空格键会引导进入充能小站；答题面板内空格不操作其他功能，可以使用数字键盘或键盘输入。正确答案会自动提交并播放祝贺音效；错误答案点击「送出答案」或按 Enter 后，会播放重试音效。充满能量会触发爱心、光环与彩色星星的庆祝动画。
- 「作弊模式」默认关闭；开启后，所有参与抽取的宝物等概率出现。

目前共有 25 件宝物。普通模式按配置权重独立抽取；作弊模式下，每件概率为 4%。两种模式都允许重复抽中同一件宝物。

能量、题目难度、收藏和声音、动画偏好使用 `localStorage` 保存。作弊模式每次打开或刷新页面都会重置为关闭；浏览器无法保存收藏时，页面会给出提示。

## 项目结构

```text
75-magic-machine/
├── game-config.json     # 能量上限、消耗、奖励与数学题范围
├── treasures.json       # 宝物配置
├── assets/              # 独立 SVG 插画
├── src/
│   ├── template.html    # 页面结构
│   ├── style.css        # 基础布局、宝物效果与响应式样式
│   ├── gacha.css        # 抽奖机灯光与演出动画
│   ├── engine.mjs       # 配置校验、概率抽取与历史记录校验
│   ├── energy.mjs       # 能量规则、存档恢复与数学出题
│   ├── recharge.js      # 充能小站、数字键盘与答题反馈
│   ├── energy.css       # 能量格、低能量预警与充能面板
│   ├── chamber.js       # 魔法舱小球运动、碰撞与选球
│   ├── audio.js         # Web Audio 合成音效和中奖音乐
│   └── app.js           # 开奖流程、粒子、交互与本地收藏
├── build.mjs            # 将源文件和资源打包为单个 HTML
├── tests/               # 抽奖逻辑与浏览器验证
└── index.html           # 可直接打开的游戏
```

一次抽奖由 `app.js` 串起各个阶段：

```text
启动 → 注入能量 → 小球翻腾 → 选球落下 → 摇晃开壳 → 宝物揭晓 → 收藏
```

`engine.mjs` 在启动时选定结果，`chamber.js`、CSS 动画、粒子和音效共同完成演出。魔法舱展示的小球数量和碰撞过程不影响概率。宝物揭晓时才写入收藏，抽奖进行中会锁定重复启动和模式切换。

## 配置宝物

编辑 `treasures.json` 中的 `treasures` 数组：

| 字段 | 作用 |
| --- | --- |
| `id` | 唯一、稳定的标识，用于关联收藏 |
| `name` / `description` | 宝物名称和揭晓描述 |
| `rarity` | `common`、`rare`、`super`，决定稀有度展示；`super` 带有额外的开奖预告 |
| `weight` / `enabled` | 抽取权重和启用状态，停用或零权重宝物不参与抽取 |
| `appearance` | SVG 路径、备用图标和主题配色 |
| `effects` | 揭晓动画、持续粒子、中奖音效和效果参数 |

普通模式下，单件宝物的概率为它的权重除以所有参与抽取宝物的总权重。稀有度和权重可以分别配置，作弊模式只临时改变抽取概率。

插画放在 `assets/` 下，通过 `appearance.image` 引用。效果 ID 在 `src/engine.mjs` 注册；动画、粒子和声音分别由 CSS、`src/app.js` 和 `src/audio.js` 实现。配置只保存数据，未知效果会降级到基础效果。

能量参数集中在 `game-config.json`：`energy` 定义初始值、上限、预警阈值、抽奖消耗和答题奖励；`math` 定义默认难度和各档范围。抽奖启动时扣除并保存能量，刷新不会恢复满格；流程异常且未发放宝物时退回本次消耗。作弊模式只调整宝物概率，仍消耗能量。

## 本地开发

构建和逻辑测试需要 Node.js，无需安装第三方依赖。

```sh
npm run build   # 生成 index.html
npm test        # 验证配置、概率抽取、能量与数学题逻辑
npm start       # 启动本地服务，需要 Python 3
```

本地服务地址为 `http://localhost:7575`。修改源文件、宝物配置或插画后，运行 `npm run build` 更新游戏。

`tests/` 中还提供可选的 Playwright 浏览器验证脚本，用于检查完整开奖流程、键盘交互、收藏保存、能量耗尽、答题奖励和手机布局。
