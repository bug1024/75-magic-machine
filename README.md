# 75's MAGIC MACHINE

王卿梧的魔法抽奖机 · 魔法扭蛋。13 件宝物、单键抽取、专属开奖效果和本地收藏，无框架、无 CDN、无后端。

## 第二版体验

本轮精简了主界面说明文字，并加强小球翻腾与碰撞形变、机器摇摆、落球弹跳、摇球幅度、飞散开壳、宝物弹出和扩散冲击波。柔和模式仍保留简化动作。

开奖改成「注入能量 → 魔法球碰撞翻腾 → 选中并移向出口 → 落入托座 → 三次晃动与裂缝发光 → 球壳打开、宝物升起」。40 颗五色灯珠沿魔法舱追逐，速度随阶段变化。普通流程约 7 秒，大奖约 9 秒。

声音使用 Web Audio 合成启动上扬音、小球碰撞音、落球与摇球音；中奖音乐包含鼓点、低音、和弦和主旋律，三档稀有度各有一段乐句，噗噗宝宝另有搞笑音效。声音通过统一音量总线和压缩器输出，静音会停止当前声音。后台暂停视觉和音频进度，柔和模式保留流程反馈并减少运动。

`versions/v1.html` 保留上一版，可单独打开对比。第二版继续使用同一套宝物 ID 和收藏存储键，已有收藏不需要迁移。

## 直接试玩

双击 `index.html`，用 Chrome / Edge 打开。按空格键或点击「开启魔法」。右上角可切换声音、柔和动画和全屏，下方「我的宝藏」查看收藏。所有奖励都是虚拟的魔法宝物。

交付 HTML 已内嵌配置和 SVG 插画，可以单独复制使用。本地收藏保存在当前浏览器中；隐私模式、禁用存储或移动文件可能影响保存，保存失败时界面会提示。

## 修改与构建

需要 Node.js（没有第三方依赖）：

```sh
npm run build
npm test
npm start
```

`npm start` 需要 Python 3，打开 http://localhost:7575。不要直接修改生成的 `index.html`，修改源文件后运行构建。

## 宝物配置

编辑 `treasures.json` 的 `treasures` 数组。保留原来的星光公主裙、彩虹独角兽、月亮城堡，并新增云朵小海豚、吱吱猫头鹰、摇摇雪王、泡泡魔法刷、爱心小猪存钱罐、丹鹤流云汉服裙、追彩虹披风、珍珠美人鱼套装、翅膀精灵宝石、噗噗开心宝宝。前六件新宝物的插画参考用户提供的照片。

当前总权重为 38，每件概率为其权重 / 38；普通、稀有、超级宝物总权重分别为 26、9、3。魔法舱最多展示八颗球，每次抽取轮换形象，并保证中奖宝物有对应的小球。噗噗宝宝使用 `bubble-pop` 泡泡效果和 `bubble-giggle` 搞笑短音。

| 字段 | 用途 |
| --- | --- |
| `id` | 唯一且稳定的 ID；改名称不改变收藏归属 |
| `name` / `description` | 揭晓标题与魔法描述 |
| `rarity` | `common`、`rare`、`super`；super 额外播放大奖预告 |
| `weight` / `enabled` | 正数权重、是否参加抽取 |
| `appearance.image` | `assets/` 下的 SVG 文件，构建时内嵌 |
| `appearance.icon` | 图片缺失或加载失败时的备用图标 |
| `appearance.primaryColor` / `accentColor` | 六位十六进制配色 |
| `effects.reveal` | 揭晓效果 ID |
| `effects.ambient` | 结果停留时的粒子效果 ID |
| `effects.sound` | 合成旋律 ID |
| `effects.params.durationMs` | 庆祝停留 1500–4000 毫秒 |
| `effects.params.particleCount` | 粒子数量 10–160，柔和模式自动降低 |

现有效果：

| 揭晓 | 氛围 | 声音 |
| --- | --- | --- |
| `sparkle-bloom` 星光扩散 | `floating-stars` 浮动星星 | `magic-chime` 魔法铃声 |
| `rainbow-ring` 彩虹光环 | `rainbow-trail` 彩色粒子 | `rainbow-song` 彩虹旋律 |
| `moonrise` 月光升起 | `golden-rain` 金色星雨 | `royal-fanfare` 城堡旋律 |

新增宝物可以复用效果。新增效果时，在 `src/engine.mjs` 注册 ID，并在 `src/style.css`（揭晓）、`src/app.js`（粒子/声音）实现对应表现。未知效果自动降级为基础星光效果。配置仅包含数据，不执行脚本。

## 源文件

- `src/template.html`：界面结构。
- `src/style.css`：机器、布局、效果、响应式与柔和动画。
- `src/gacha.css`：第二版灯珠、能量管道、魔法舱、开壳与升起动画。
- `src/chamber.js`：小球运动、碰撞和选球出口。
- `src/audio.js`：分层合成音效、节奏和四种中奖乐句。
- `src/engine.mjs`：配置校验、权重抽取、记录校验。
- `src/app.js`：开奖状态、声音、粒子、收藏和浏览器存储。
- `assets/*.svg`：13 个独立宝物插画。
- `build.mjs`：生成单文件交付。

抽中结果在启动时选定，扭蛋过程只是演出，球的数量与运动不决定概率。结果揭晓时写入收藏，每次最多写入一次；刷新进行中的抽奖会取消尚未揭晓的结果。后台标签页暂停开奖进度。历史保留最近 1000 次，删除配置中的宝物不会立即删除它的历史收藏。
